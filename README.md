# kangseyoung

VFX 파이프라인 툴을 만들면서 코딩을 시작했고, 그 과정이 재미있어 컴퓨터공학을 복수전공하게 되었습니다.

지금은 시스템 인프라, 자동화, Linux 환경, API 연동, 데이터 처리에 관심이 있으며, 여러 시스템을 연결하고 반복 작업을 줄이는 개발을 좋아합니다.

또한 AI/LLM이 앞으로 개발, 문서화, 디버깅, 데이터 처리 과정에서 중요한 도구가 될 것이라고 생각해 LLM API, 프롬프트 설계, 응답 품질 개선, AI-assisted workflow를 공부하고 있습니다.

**컴공의 붐은 다시 온다. 단, AI를 잘 다루고 시스템을 이해하는 사람에게.**

## AI/LLM 활용 방향

AI를 단순히 코드를 대신 작성하는 도구가 아니라, 개발 과정에 함께 들어오는 보조 시스템으로 활용하고 있습니다.

특히 다음과 같은 방향에 관심이 있습니다.

- 긴 문서나 강의자료를 구조화된 Markdown으로 변환
- LLM 응답을 JSON / CSV 형태로 저장하고 비교
- 프롬프트 버전별 결과를 비교해 응답 품질 개선
- 오류 로그를 분석하고 가능한 원인과 해결 방향 정리
- README, 검증 체크리스트, 기술 문서 초안 작성
- 반복적인 개발 작업을 자동화하는 AI-assisted workflow 구성

## Projects

### Lecture-Companion-Agent

강의 PDF나 슬라이드 내용을 바탕으로 학습용 Markdown 노트와 설명을 생성하는 LLM 기반 문서 처리 프로젝트입니다.

이 프로젝트에서는 단순히 LLM에게 요약을 요청하는 것이 아니라, 입력 자료를 구조화하고, 프롬프트 형식을 설계하고, 결과물을 Markdown/PDF 형태로 정리하는 흐름을 실험했습니다.

**Keywords:** Python, LLM API, Prompt Engineering, Markdown, PDF Processing, Document Automation

---

### landing-agent-harness

랜딩페이지 제작 과정을 AI-assisted workflow로 실험한 프로젝트입니다.

기획, 구현, 검토, 문서화 과정을 분리하고, AI를 활용해 코드 작성뿐 아니라 QA 체크리스트와 README 정리까지 함께 수행하는 흐름을 구성했습니다.

**Keywords:** TypeScript, Next.js, Supabase, AI-assisted workflow, QA checklist, Documentation

---

### capstone-repo-polisher

정리되지 않은 프로젝트 저장소를 포트폴리오용 공개 저장소로 바꾸기 위한 프롬프트 기반 정리 워크플로입니다.

README 구조, 프로젝트 설명, 공개 가능한 파일 정리, 민감정보 점검 등 GitHub 포트폴리오 정리에 필요한 과정을 자동화하는 방향으로 설계했습니다.

**Keywords:** Prompt Workflow, GitHub Portfolio, Documentation, Repository Cleanup

---

### deadline-renderfarm-automation

학교 실습실 환경에서 진행했던 Deadline 기반 렌더 자동화 프로젝트입니다.

현재 관심사는 렌더팜 자체보다는, 이 프로젝트에서 경험한 시스템 연동, 경로 표준화, 오류 로그 분석, 자동화 설계입니다. 여러 컴퓨터와 외부 서비스를 연결해 작업 흐름을 자동화한 경험으로 정리하고 있습니다.

**Keywords:** Python, System Automation, MongoDB, Google Sheets API, Troubleshooting, Workflow Automation
